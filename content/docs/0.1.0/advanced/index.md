# Advanced

Once you're past the basics, these pages cover the things that matter
before you rely on PylsRun somewhere real: exactly what's tested versus
best-effort on which platforms, the safety conventions used throughout
the API, performance characteristics, and how the package is built and
distributed.

- **[Platform Support](/docs/0.1.0/advanced/platform-support)** — a
  feature-by-feature matrix of what's actually tested versus written-but-
  unverified.
- **[Safety & Performance](/docs/0.1.0/advanced/safety-and-performance)**
  — raw-memory safety boundaries, capability checks, and where the performance
  actually comes from.
- **[Packaging & Builds](/docs/0.1.0/advanced/packaging-and-builds)** —
  `setup.py` vs `CMakeLists.txt`, debug builds, and how wheels get built.
